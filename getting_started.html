Seismic Facies Clustering Tool — Getting Started

Version 6 · unsupervised facies analysis of SEG-Y attribute volumes (3D) or lines (2D): check and clean the data, reduce dimensions, cluster, compare, and export only the models you choose as SEG-Y files.

Both versions keep your data on your own computer. The web version runs entirely inside your browser tab — the files you add are never uploaded anywhere.

1 · Web version

  1. Open the link above in Chrome, Edge or Firefox (a computer, not a phone). The first visit downloads about 90 MB and takes up to a minute; later visits are faster.
  2. Step 2 in the sidebar: Browse files and add your SEG-Y attribute volumes (and the amplitude volume, if you want it behind the clusters). Check the inline / crossline byte locations — the header viewer helps if you are unsure.
  3. Pick the attributes, click Load attributes, and work through the tabs left to right.
  4. On the Export tab, export, then save each file with its download button. Save your session too (sidebar, Step 7) — load it later together with the same SEG-Y files to carry on.
Closing or reloading the tab clears everything that is not downloaded. Browsers allow a web page about 2 GB of memory in total, so keep all files together to about 600 MB: crop large volumes first (the time range saves the most), use fewer attributes, or use the downloadable version.

2 · Downloadable version (Windows)

  1. Download SeismicClusterTool-…-windows-x64.zip from the link above (under Assets).
  2. Right-click the zip → Extract All… (do not run it from inside the zip). Any folder works, e.g. Documents.
  3. Double-click Start Seismic Cluster Tool.bat. A black window opens, then the tool opens in your browser. Keep the black window open while you work; close it to stop the tool.
“Windows protected your PC” on the first start: click More info → Run anyway. This appears because the tool is new and not yet code-signed.

New versions

When a new version is out, the tool shows a note under its title with a download link. Unzip the new version next to the old one and use that; your session files keep working. Delete the old folder when you are happy.

3 · SEG-Y tips

  • All attribute volumes must be on the same grid (same inlines, crosslines and time samples) — e.g. all computed from one seismic volume.
  • Inline / crossline numbers are read from the trace headers (SEG-Y standard bytes 189 / 193). If the grid summary in the sidebar looks wrong (one inline, mostly empty), open the header viewer → Find inline / crossline bytes.
  • 2D lines: choose Survey type: 2D line in Step 2. The tool then asks for one trace-number byte instead (the CDP number, byte 21, by default; if that field is empty, traces are taken in file order). Work on one 2D line at a time: all attributes must come from the same line. The line is shown as a section; time slices and crosslines need a 3D volume.
  • Any trace order and missing traces are fine. IBM or IEEE floats and integer formats are read; outputs are always IEEE float (format 5) with your first file's headers.
